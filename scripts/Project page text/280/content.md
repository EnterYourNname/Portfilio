## My Role & Outcome
I collaborated with another UX/UI designer and a developer to create the Smina shelf configurator. My responsibilities included:
- Adapting and expanding an existing component library used across the website
- Creating low-, mid-, and high-fidelity wireframes based on internal feedback and testing
- Delivering final UI screens ready for development
- Producing 3D renders and visual assets for all modular components featured in the configurator
